## About Me

I'm **Joseph Olawale**, a Nigerian developer building across the intersection of **software engineering, AI, automation, APIs, and digital experiences**.

I've spent the last **3 years** learning by building — from backend systems and developer tools to bots, APIs, automation workflows, and full-stack applications.

I enjoy understanding how things work beneath the surface, experimenting with new technologies, and turning ideas into software that is actually useful.

I don't really like following the usual path.

**If there's a better way to build it, I'll probably try it.**

## My Philosophy

> **Build it. Break it. Understand it. Build it better.**

I don't believe you need to know everything before you start.

I'd rather build something I don't fully understand, hit the wall, figure out why it broke, and come back with a better solution.

**Curiosity → Experiment → Failure → Understanding → Improvement.**

That's pretty much how I learn.
